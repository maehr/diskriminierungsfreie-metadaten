# Section Spec: Frontmatter

source: `manuscript/sections/00-frontmatter.qmd`

## Purpose

- Set expectations that the handbook is the current working manuscript of a Living Document.
- Inform readers that the handbook includes historical material that can contain discriminatory language, imagery, or representations.

## Required Elements

- Keep both callouts.
- Keep the GitHub feedback link.
- Name the current version and the monograph in preparation at Bielefeld University Press.
- Link the DOIs of versions 1.0.0 and 1.0.1 as published iterations.
- Call each release a version or an iteration. Do not use edition terms.
- Use neutral terminology for reader guidance (prefer "Hinweis" / "Content Note" over warning language).

## Structure

- No headings required.
- Two consecutive callout blocks.

## Citation Expectations

- No citations required.
