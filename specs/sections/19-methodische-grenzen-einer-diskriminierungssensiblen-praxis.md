# Section Spec: Methodische Grenzen einer diskriminierungssensiblen Praxis

source: `manuscript/sections/05-praxis-09-methodische-grenzen-einer-diskriminierungssensiblen-praxis.qmd`

## Purpose

- Set epistemic and practical limits: discrimination-sensitive metadata work can reduce harm and improve transparency, but cannot fully remove historical/structural bias.
- Encourage "interpretative humility" and explicit documentation of uncertainty and trade-offs.

## Required Elements

- Preserve the argument that historical data is selective (creation, transmission, digitization) and cannot be fully de-biased.
- Preserve the emphasis on measurement limits and proxy variables (OCR/HTR errors; normalization effects; group-differential error).
- Preserve the discussion of fairness trade-offs and the need to treat them as governance decisions.
- Preserve the ecological and legal/ethical constraints framing.

## Structure

- Single `##` heading plus 2-4 dense paragraphs; no subheadings required.

## Citation Expectations

- If adding specific claims about ecological impact, privacy, or measurement error magnitudes, cite sources.
