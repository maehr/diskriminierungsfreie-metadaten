# Section Spec: Einleitung

source: `manuscript/sections/02-einleitung.qmd`

## Purpose

- Define the handbook's scope, audience, and motivation.
- Provide a working definition of discrimination for the handbook.
- Preview the structure: theory concepts + practice phases across the research data lifecycle.
- Give readers an orientation aid for navigating the handbook.

## Required Elements

- Audience statement: historians, archivists, librarians, data curators; universities and GLAM.
- Motivation: why metadata matters for findability, access, interoperability, reuse.
- Example of missing contextualization in existing catalog metadata (Plakatsammlung Basel "Frauenstimmrecht, Nein").
- Handbook definition of discrimination (broad, includes many protected/attributed characteristics).
- Two-part structure description (theory + practice).
- Seven practice phases list and the citation grounding the lifecycle model (`@higgins2008`).

## Required Figures

- The Plakatsammlung Basel screenshot figure (image + alt text).
- Mermaid figure `fig-metadata-1` (linearized lifecycle model).
- Mermaid figure `fig-metadata-2` (decision/orientation diagram).

## Structure

- `# Einleitung`.
- Flow: audience/scope -> why metadata -> motivating example -> definition of discrimination -> overview of theory topics -> practice lifecycle phases -> two mermaid diagrams -> author positionality disclosure -> living document + contribution channels.

## Citation Expectations

- Retain `@higgins2008` in the lifecycle introduction.
- Any additions that assert facts about current archive practices should be backed by citations or framed as examples/observations.
