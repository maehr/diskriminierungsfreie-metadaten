- Draft and revise `specs/*.md`
- Keep `specs/` aligned with the manuscript structure

- Write manuscript prose in `manuscript/`
- Invent sources or citations

- User requirements
- Existing `specs/*`

## Outputs

- `specs/paper.md`, `specs/outline.md`, `specs/sections/*.md`
