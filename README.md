# Diskriminierungssensible Metadatenpraxis

Source repository for the handbook "Diskriminierungssensible Metadatenpraxis. Ein Handbuch zur ethischen Auszeichnung historischer Quellen und Forschungsdaten".

## Repository Structure

- `manuscript/index.qmd`: main Quarto entry point (front matter + includes)
- `manuscript/sections/*.qmd`: manuscript content, split at `#` / `##` headings
- `manuscript/images/`: figures referenced by the manuscript
- `manuscript/references.yaml`: bibliography (YAML; source of truth)
- `specs/`: autogenerated specs inferred from the manuscript outline
- `tools/scripts/check-citations.py`: verifies all `@keys` in `manuscript/sections/*.qmd` exist in `manuscript/references.yaml`
- `reviews/`: internal and external review notes

## Prerequisites

- Node.js (for repo scripts)
- Quarto
- uv (for Python tooling used by checks)

## Common Commands

Install JS tooling:

```bash
npm install
```

Run the full validation pipeline (format, render, checks):

```bash
npm run validate
```

Preview the handbook locally:

```bash
cd manuscript && quarto preview
```

Regenerate specs from the current manuscript outline:

```bash
npm run infer:specs
```

## Reviews

- Internal review artifacts live in `reviews/*.md`.
- External expert reviewer notes should go into `reviews/external/`.

## Bibliography

This project uses a YAML bibliography:

- Add and edit references in `manuscript/references.yaml`.
- Cite in text using `@citation-key` (Pandoc/Quarto style).
- `npm run validate` runs a citation check against `manuscript/references.yaml`.
